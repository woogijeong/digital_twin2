뉴로메카 협동로봇 디지털 트윈 앱 PRD
1. why - 목적

* 실물 로봇 동작을 그대로 3D 모델링해서 GUI 화면으로 보기 위해
* 현재 좌표값 확인으로 로봇 상태 파악
* 포트폴리오 시연용 시각적 데모 자료 확보

2. who - 타깃 사용자

* 본인(개발자) - 로직 검증용
* 채용 담당자/면접관 - 포트폴리오 시연 대상
* 팀 프로젝트 협업자(OPC-UA/MES 대시보드 연동 시)

3. User flow

* 앱 실행 → 로봇 3D 모델 로드 → 현재 좌표값(X,Y,Z,Rx,Ry,Rz) 화면 표시
* 좌표 입력/변경 → 파이썬을 통해 로봇 모델 자세 실시간 애니메이션 갱신
* 현재 좌표값 실시간 갱신 표시

4. 기능 요구 사항
P0 - 핵심 기능

* 로봇 3D 모델 렌더링 (IndyDCP3 형상)
* 현재 좌표값(X, Y, Z, Rx, Ry, Rz) 텍스트 표시
* 좌표 입력/변경 시 로봇 모델 자세 갱신
* 파이썬을 통해 실시간 애니메이션 확인

P1 - 추가 기능

* 관절/엔드이펙터 이동 애니메이션 (좌표 간 보간)
* Pick 상태 시각화 (그리퍼 닫힘 + 물체 부착)
* Place 상태 시각화 (그리퍼 열림 + 물체 분리)
* pallet2x2 좌표 시퀀스 순차 실행
* 재생/일시정지/리셋 컨트롤
* 재생 속도 조절 (배속)
* 그리퍼 무게(0.4kg) 반영한 부하 표시
* 실제 로봇 컨트롤러(192.168.3.4) 연동 - 실좌표 실시간 미러링
* 비상정지(E-STOP) 버튼 - 컨트롤러 모션 즉시 정지(stop_motion, category-1) + 트윈 애니메이션 즉시 정지. 트윈이 컨트롤러를 명령하는 유일한 예외(모션을 멈추기만 하며, 시작시키지 않음)
* 충돌/경로 이탈 감지 알림
* 좌표 시퀀스 편집 기능
* 다크모드/라이트모드 UI
